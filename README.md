## Пояснения к условиям

- Урок 3: программа ввода этапов не проверяет биологические ответы — это
  соответствует условию начального урока. Последнее поле предназначено для
  `Homo sapiens sapiens`.
- Урок 4: при нулевом знаменателе выводится понятное сообщение об ошибке.
- Урок 5: для нечётного числа выводятся и описание, и отдельно требуемое
  сообщение «число не является четным».
- Урок 7: группы пробелов заменяются одним; одиночный пробел в начале или
  конце не удаляется, так как удаления пробелов условие не требует.
- Урок 11: в условии есть опечатка `import collection`; используется правильное
  имя стандартного модуля `collections`. Проверяются отсутствующие ID; после
  удаления записи идентификаторы не переиспользуются. Список факториалов
  быстро растёт: для демонстрации удобно вводить 3 или 4.
- Урок 16: `go_right()` увеличивает **x**. Указанное в условии увеличение y
  дублировало бы `go_up()`. В `count_moves` действием считается как перемещение,
  так и `evolve`/`degrade`. Поиск A* возвращает точный минимум без изменения
  положения объекта. Для больших расстояний поиск может занимать больше времени.

## Урок 23 — Лесной патруль

```text
python lesson_23/game.py
python lesson_23/game.py --width 16 --height 10 --seed 7
python lesson_23/game.py --ascii
python lesson_23/game.py --load --save-file savegame.json
python lesson_23/game.py --width 8 --height 6 --seed 7 --demo 100 --ascii
```

При обычном интерактивном запуске можно выбрать размер поля. Один игровой тик
проходит каждую секунду, даже если игрок не нажимает клавиши.

| Клавиша | Действие |
|---|---|
| W, A, S, D | Переместить вертолёт на одну клетку |
| F или пробел | Потушить одно дерево под вертолётом или в соседней клетке |
| H | В госпитале восстановить здоровье за 20 очков |
| U | В магазине купить дополнительный резервуар за 30 очков |
| K | Сохранить игру в JSON |
| L | Загрузить игру из JSON |
| Q или Escape | Выйти |

Над водой резервуары заполняются автоматически. Спасённое дерево приносит
10 очков; сгоревшее отнимает 5. Пожары распространяются на соседние деревья,
деревья периодически вырастают. Есть облака и грозы: облака скрывают часть
карты, молнии зажигают деревья и повреждают вертолёт. У игрока три жизни.
После потери жизни вертолёт появляется в госпитале. Госпиталь находится
в левом верхнем углу, магазин — в правом нижнем.

Сохранение содержит карту, пожары, погоду, время, параметры вертолёта и
состояние генератора случайных чисел. После загрузки симуляция продолжается
с того же состояния. Неверный или повреждённый файл не выполняется как код.

В режиме `--ascii` вместо эмодзи используются символы. При перенаправленном
stdin доступен пошаговый ввод по одной команде в строке. `--demo` выполняет
автоматическую демонстрацию без ожидания и без записи сохранений.
